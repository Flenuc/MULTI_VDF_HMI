# VarioField 0.3.9

## Sprint B — Accesibilidad (labels / live regions)

- Cabeceras de sección con `accessibilityRole="header"`
- `accessibilityLabel` (y hints) en campos de texto, switches y chips
- Listas seleccionables USB / Bluetooth / módulos MQTT con role + estado selected
- Anuncios: `statusLine` y progreso con `accessibilityLiveRegion="polite"`
- `ErrorBanner` con `accessibilityLiveRegion="assertive"`

Incluye Sprint A (0.3.8): control Marcha/Paro separado, sync «Comparar primero» primario, badge ≠ Diferente.
